🧩 새 게임 계속 누적하기 가이드

1단계: 새 게임 폴더 생성

games/01-triangle/ 처럼 원하는 게임 이름으로 폴더와 index.html을 만듭니다.

2단계: 데이터 레지스트리에 등록

js/games-data.js 파일의 배열에 아래 항목을 추가하면 메인 화면에 즉시 등록됩니다:

{
  id: "triangle-hunter",
  title: "삼각형 탐정단",
  unit: "1단원. 삼각형",
  semester: 2,
  thumbnailIcon: "🔺",
  path: "games/01-triangle/index.html",
  isReady: true,
  skills: ["이등변·정삼각형 성질", "삼각형 분류"]
}

3단계: 공통 사운드 및 스토리지 연동

각 게임 페이지에서 window.soundFX.correct()나 window.mathStorage.saveGameResult(gameId, score, stars)를 호출하면 별점과 점수가 메인에 자동 누적됩니다!
